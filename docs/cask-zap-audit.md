# Cask cleanup audit

Audited all 17 casks at the versions below on 2026-10-16. Every cask quits its
verified bundle identifier with a TERM fallback. Ordinary uninstall preserves
user data; `--zap` opts into removing the documented local state. Each cask
includes its macOS caches, HTTP storage and cookies, logs, preferences, saved
state, and WebKit storage. Paths that do not exist are harmless.

Cleanup stops app-owned services and helpers before removing their data.
Keychain cleanup repeats until the app-owned service has no matching local
items; only item-not-found is a successful no-op. CLI cleanup normalizes link
targets before checking app ownership, preserving foreign links and commands.
TUICommander's copied CLI must also pass its identifier and Developer ID team
requirement. Shared models are scoped to the verified model directories and
repository locks, rather than the entire SDK or Hugging Face cache.

This audit covers default local storage and known legacy paths. Custom data or
model locations, user-selected documents and projects, developer test/build
profiles, external agent installations, system relays, and remote/iCloud data
need explicit ownership and cleanup rules. Shared model downloads used by an
app are included even when another app can reuse them. macOS filesystem and
Keychain permissions still apply; permission errors must not be treated as
successful cleanup.

Localvoxtral preflights shared settings before writing. It preserves unrelated
content even through config symlinks, retains file permissions, and refuses
concurrent edits, damaged markers, edited status-line wrappers, unknown JSON
schemas, and ambiguous TOML forms instead of guessing. Such errors require
manual resolution before retrying zap.

Run `brew ruby scripts/test-cask-zap.rb` for temporary filesystem fixtures for
all 17 casks. The suite checks data removal, unrelated data preservation,
ordinary-uninstall behavior, helper ownership, credential scope, and error
propagation. Processes, launch services and Keychain access are faked; the
suite never uninstalls an app or reads real credentials.
